# Galleo v1.2.3

## Improvements

* **Unified Similar Media & Visual Search Radius:** Aligned the Duplicate & Similar Media clustering algorithm with the default visual similarity radius (`radius = 18`), enabling full burst sequences and multi-shot compositions to stay together in a single group in the Similar Media view for easy one-click culling.
* **Synchronized Similarity Settings:** Updating the Visual Similarity Radius slider in Settings now synchronizes both visual similarity search in Browse Media and background duplicate clustering in Duplicate Audit.
* **Standardized Release Automation:** Added the automated `release-version` skill for consistent changelog generation, testing, and CI/CD release publishing.
